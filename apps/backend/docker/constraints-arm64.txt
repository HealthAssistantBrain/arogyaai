# ──────────────────────────────────────────────────────────────────────────────
# constraints-arm64.txt — ARM64 / Apple Silicon pip constraints
#
# This file is used as `pip install --constraint constraints-arm64.txt` on
# ARM64 builds to prevent NVIDIA CUDA packages from being installed as
# transitive dependencies of PyTorch, sentence-transformers, etc.
#
# HOW IT WORKS:
#   pip constraints cannot truly "block" a package, but we can pin NVIDIA
#   packages to empty-marker versions that effectively exclude them.
#   Combined with pre-installing CPU-only torch (which has no nvidia deps),
#   this ensures pip never resolves nvidia-* packages.
#
# NOTE: This file does NOT modify requirements.txt.
# ──────────────────────────────────────────────────────────────────────────────
